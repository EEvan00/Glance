# Glance 已确认的产品决定

这些决定来自用户已明确确认的要求。代码审查和技术建议不能自行覆盖它们；改变决定需要用户明确授权，并同步更新此文件。

- 摘要页和天气详情页均不显示独立的 Apple Weather 标志/来源链接行。该行曾被明确要求删除，后续开发保持删除状态。不能把闲置的来源组件误判为遗漏并重新挂接。
- v2 底部模块支持八格自定义；默认布局及上方卡片布局保持已确认的外观。来源行不能额外撑高摘要面板。
- 卸载必须完整执行：恢复系统 MagSafe 控制、注销辅助服务及登录项、移除 Claude 集成、将应用移入废纸篓，再退出。保存的设置和系统快捷指令按确认框说明保留。
- 私钥不进入源码、Git 历史、日志或安装包。发布所需凭据仅通过加密 Actions Secrets 使用。

## 2026-10-16 已确认调整（用户已授权发布 2.0.2 Build 23）

- 天气快捷指令精简为一个 **Glance Weather**，同时输出当前天气和小时预报；摘要与详情共用结果，保留旧版主快捷指令的更新入口，不自动删除用户安装的旧预报快捷指令。
- 等待定位授权超时、系统定位服务关闭、定位权限被拒绝及无法获取坐标分别处理；超时不再提示用户开启已开启的定位服务。
- Codex 与 Claude 图标跟随浅色／深色外观，使用同一套系统主色规则。

- 应用图标沿用正式版 2.0.1 Build 19 的原始 `AppIcon.icns`，作为唯一打包来源；移除旧 SVG，禁止回退生成。构建和 CI 必须校验已确认的图标校验和，图标缺失或变更时停止打包。测试版身份通过版本／Build 和应用标识区分，不自行替换图标。

- 浅色模式下额度条与音量条共用灰色轨道；各摘要模块统一使用可见的灰色细边框。深色模式保留已有轨道与边框颜色，布局和几何尺寸不变。

- 显示详情的深色模式、Night Shift、True Tone 三个按钮，开启时固定为蓝色圆形背景和白色图标，不受浅深色外观或系统强调色影响。

## 发布前的行为核对

发布负责人必须先读取本文件及最近用户决定，再给审查者明确的产品边界。
用户测试通过后，如候选包出现新的可见行为变化，必须单列变化供用户确认。
工程验证与产品确认分别记录；CI 通过不能替代“界面符合已确认要求”。
遇到技术、平台或外部规则与产品决定的冲突，先说明事实并讨论解决方式，不自行恢复已被删除的 UI。
